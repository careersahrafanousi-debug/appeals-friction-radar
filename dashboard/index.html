Appeals Friction Radar

Pathway Appeals Services (fictional) · 3,966 appeals · 1 January to 30 September 2026. Turnaround averages 14.9 days and only 49.6% of appeals meet SLA. Urgent appeals carry a 7-day target and take 15.5 days — slower than the Standard queue they are supposed to jump.

Fully synthetic data · no employer, patient or confidential information

How this page is built. Every value comes from a SQL query stored in dashboard/dashboard_config.json and run against data/appeals.db by src/build_dashboard.py. Nothing is typed in by hand, so the dashboard cannot drift away from the analysis in sql/. Rebuild with python src/load_sqlite.py && python src/build_dashboard.py.

Limitations. Stage durations are derived from event timestamps, so an appeal that was worked without a logged event shows as waiting. Friction Score weights are analyst judgement and were not fitted to SLA outcomes, so the score ranks appeals but does not predict a breach probability. Calendar days are used throughout because the source has no business calendar, which inflates every stage by weekends. The data is fully synthetic — the method transfers, the conclusion does not.

Source: synthetic data generated by src/generate_data.py. No employer data, patient information, protected health information or confidential business information is used.
